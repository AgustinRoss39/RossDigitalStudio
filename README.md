# Ross Digital Studio — V1

Sitio comercial de Ross Digital Studio, construido con Next.js App Router + TypeScript.

La V1 incluye Home, Webs, Invitaciones, Portfolio, responsive, CTA a WhatsApp, SEO básico y portfolio real.

El contenido comercial está centralizado en `lib/data.ts` y el número de WhatsApp se configura con `NEXT_PUBLIC_WHATSAPP_NUMBER`.
